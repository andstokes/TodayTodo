# 发布前手工验收清单

建议首次验收使用不含隐私的测试内容，并先保持开机启动关闭。

## 基础与窗口层级

- [ ] 双击 `TodayChecklist.exe` 后出现“今日清单”，不出现 UAC 提示。
- [ ] 再次双击程序不会出现第二个窗口，而是唤醒现有窗口。
- [ ] 文件资源管理器、窗口标题栏和系统托盘显示同一枚蓝色“日历＋勾选”图标；托盘小尺寸下轮廓仍清楚。
- [ ] 标准模式下程序不置顶；打开记事本后，记事本能正常遮住它。
- [ ] 主窗口不显示“今日清单”软件名，只显示日期、历史记录、齿轮和隐藏图标；历史记录图标是清晰的“日历＋勾选”线性符号。
- [ ] 点击隐藏图标后窗口消失，托盘双击可恢复；图标悬停提示和键盘焦点可用。
- [ ] 托盘菜单的显示、设置、导入、导出、退出均可用。

## 任务规则

- [ ] 点击底部“＋”出现行内编辑卡片；空标题不能保存，中文、英文和 emoji 可正常保存。
- [ ] 行内编辑可展开备注和重复规则；Enter 保存、Esc 取消、备注区 Ctrl+Enter 保存。
- [ ] 草稿在隐藏到托盘后仍保留；真正退出或迁移前出现保存/放弃/取消提示。
- [ ] 勾选后任务移到下方、显示删除线，并以灰化背景和较低不透明度弱化；文字仍可辨认，复选框仍可取消。
- [ ] 双击任务可编辑标题和备注，退出再打开仍保持。
- [ ] 按住未完成任务卡片上下拖动可排序；复选框不会启动拖动，已完成任务固定在下方且不可拖动。
- [ ] 任务旁不再显示上移、下移、编辑和删除按钮。
- [ ] 右键任务可删除，Shift+F10 也能打开菜单；删除后可撤销，停止重复后再撤销会同时恢复重复规则。
- [ ] 每天、工作日、每周、每月重复任务的下一次生成符合预期。
- [ ] 点击历史记录图标打开只读窗口；过往完成项按日期从新到旧归纳，可上下滚动，标题和备注显示正确。
- [ ] 历史记录中的任务标题使用正常文字显示，不带删除线。
- [ ] 当天完成项不会提前出现在历史记录；日期更新后保留原完成日期并进入对应日期分组，未完成任务不会进入历史记录。

## 顺延显示与时段安排（0.6.0）

- [ ] 旧数据首次打开仍显示顺延天数且不显示分隔线；设置取消顺延显示并保存后文字立即隐藏，再勾选后原天数恢复。
- [ ] 点击底部分隔线图标或主窗口内按 Ctrl+Shift+D，每次切换一次；键盘长按不反复切换，编辑草稿时也可用且草稿保留。
- [ ] 上午、下午、晚上使用 Microsoft YaHei UI 半粗体 13px，居中且两侧细线等长；浅色主题为 #3978C9，深色为 #82B8F2；“已完成”保持灰色。
- [ ] 34×30 的圆角开关开启时显示蓝色三横线与勾号、关闭时为灰色三横线与斜线；没有可见的“时段：开/关”文字。悬停提示、无障碍名称随状态变化，Tab 聚焦有边框提示，Space/Enter 可以切换。
- [ ] 设置中的分隔线选项与快捷切换一致；设置取消不改变显示，退出再打开保持最后一次已保存选择。
- [ ] 无任务时启用能看到三条分隔线，统计仍为零；全部任务完成时在“已完成”区显示，分隔线可保持空时段。
- [ ] 拖动上午线到任务下方、下午线到中间、晚上线到最后；可从上/下半张卡片前后插入，拖到列表边缘会滚动。
- [ ] 上午不能移到下午或晚上之后，下午不能越过上午或晚上，晚上不能移到下午之前；非法位置没有插入提示且松手不改变安排。
- [ ] 任务可跨线移入任意时段，包括空时段；线不可勾选、编辑或删除，不计入任务数量。
- [ ] 切换回无分隔线保留任务排列；在无分隔线模式调序，再开启后任务顺序保持，时段随新的相邻任务确定。
- [ ] 新增任务默认归上午，已完成项在单独区域置底，取消完成回原时段；删除撤销、跨日、退出重开、导出导入后时段保持。
- [ ] 浅色/深色、最小窗口尺寸及常用 DPI 下按钮、三条线与设置底部保存按钮无遮挡。
- [ ] 隔离测试目录中模拟保存失败，拖动失败时恢复原位置；显示选项失败时保留原显示。settings.json.bak 保留上次有效设置。

## 数据与恢复

- [ ] 首次保存后 `%LocalAppData%\TodayChecklist\data\tasks.json` 存在。
- [ ] 第二次保存后 `tasks.last-good.json` 存在。
- [ ] 导出得到可打开的 JSON 文件。
- [ ] 导入有效备份后任务正确替换，且 `backups` 中出现导入前备份。
- [ ] 选择非本程序 JSON 导入时显示失败，现有任务不变。

## 隔离测试模式

- [ ] 使用 --test-mode 启动后，主窗口显示绿色“隔离测试模式”提示及 %TEMP%\TodayChecklist-Test 下的随机会话路径。
- [ ] 测试模式显示虚构的今日任务、已完成任务和至少两个历史日期分组，不读取正式清单。
- [ ] 测试实例可与正式实例使用不同单实例标识；设置中的桌面模式、开机启动和数据迁移不可用，托盘不显示导入/导出。
- [ ] 运行 .\scripts\smoke-test.ps1 后在 30 秒内自动退出并报告隔离测试目录，正式位置中的路径指针、任务和设置文件哈希不变。

## 设置与回退

- [ ] 不透明度、浅色/深色和窗口位置在重启后保持。
- [ ] 开启开机启动后，当前用户 Startup 文件夹出现指向当前 exe 的快捷方式；关闭后该快捷方式被删除。
- [ ] 设置中显示当前数据根目录；选择其他磁盘的父文件夹后，实际使用其 TodayChecklist 子目录。
- [ ] 迁移完成后目标目录可完整读取，旧位置不再含任务正文，默认位置仅保留 location.json 及其 last-good。
- [ ] 选择含有其他文件的同名目标目录、网络路径、系统目录或链接目录时，迁移被拒绝且原路径保持不变。
- [ ] 拔出自定义移动磁盘后启动，程序提示重试/退出，不创建空清单或回退到 C 盘。
- [ ] 桌面模式启用后窗口位于桌面背景层，普通窗口始终在其上方。
- [ ] 桌面模式不可用时程序提示并自动改回标准模式。

## ZIP 发布验收

首版实际验收范围为 Windows 11 x64。先核对 ZIP 的 SHA-256 与同名校验文件相符，在对应发布目录另存 acceptance-manual.md，记录 ZIP 哈希、Windows 版本、验收日期、验收人及每项实际结果。不要覆盖自动生成的验收记录。

- [ ] 使用无开发工具、无额外 .NET 桌面运行时的干净环境；普通用户、断网运行。
- [ ] 使用资源管理器完整解压 ZIP；顶层只有 TodayChecklist 文件夹，内含 EXE、依赖、使用说明及 licenses。
- [ ] 从含中文和空格的路径双击 EXE，无 UAC 或依赖安装提示。
- [ ] 添加虚构任务、备注，完成任务；从托盘完全退出再启动，任务、历史记录和设置保持。
- [ ] 在该环境完成上方全部功能清单，包括单实例、托盘、图标、导入导出及可选桌面模式。
- [ ] 用虚构数据运行旧版并保存设置，导出备份、关闭旧版开机启动、退出旧版；从新目录启动新版，数据和设置正确。
- [ ] 新版可重新开启开机启动，快捷方式目标是新版 EXE；关闭后只移除本程序对应快捷方式。
- [ ] 程序目录中没有新生成的任务、设置和日志；删除旧程序目录后，独立保存的数据仍可读取。
- [ ] 全部通过后，在手工记录中写明“此 ZIP 哈希验收通过，可发布”。无法提供干净环境或有未完成项目时保留“候选包”状态。

## 自动验证命令

```powershell
.\scripts\test-release.ps1
.\scripts\publish.ps1
.\scripts\smoke-test.ps1 -ExecutablePath '解压后 TodayChecklist.exe 的完整路径'
```

发布脚本内部执行 Release 构建、测试项目构建、全部应用测试、脚本回归测试及解压后启动检查。所有构建警告视为错误，TRX 必须包含实际执行且全部通过的测试。构建、测试、发布都禁止隐式还原，依赖不足时停止。自动测试临时数据和构建临时目录位于项目 artifacts 内。

回归脚本覆盖路径越界、缓存缺失、文本禁止覆盖、同长度文件内容变化、多余/改名文件、用户数据混入、自包含清单、ZIP 往返、原子目录提交、重复版本不覆盖、构建/测试/发布非零退出后的停止、超时仅结束当前进程，以及子进程环境隔离。

发布流程的补充验收：

- [ ] 首次成功发布后记录最终目录文件哈希，再次运行 publish.ps1 应在构建前拒绝该版本，最终目录哈希保持不变。
- [ ] 用相同 ZIP 连续调用两次 smoke-test.ps1，两个会话目录不同；同机已有其他隔离会话也不影响结果。
- [ ] 人为失败验证只能在项目 artifacts 下的副本中进行，不得改动真实数据或全局依赖缓存。
- [ ] 在副本中删除一个依赖或破坏压缩包内容时，启动/校验失败，不得把该副本标记为通过。
- [ ] 发布失败现场留在 artifacts；没有新增最终版本目录，既有版本完整保留。
