# 今日清单 0.6.1（预发布候选版）

适用系统：Windows 11 x64（Intel/AMD 64 位）。完整解压 `TodayChecklist-0.6.1-win-x64.zip`，打开其中的 `TodayChecklist` 文件夹并双击 `TodayChecklist.exe`。无需安装 .NET 或 Visual Studio，不需要管理员权限。不要下载 `Source code` 来直接运行。

## 本版内容

- “上午／下午／晚上”居中显示，采用蓝色半粗体，与任务正文区分；适配深浅主题。
- 时段开关改用矢量图标：蓝色勾号表示开启、灰色斜线表示关闭，保留悬停说明、键盘焦点和无障碍名称。
- 保留任务拖拽、双击编辑、右键删除、重复任务、跨日顺延、历史记录和自定义数据位置等功能。

## 使用和更新

- 底部“＋”添加任务，勾选完成；历史图标查看过往完成项，齿轮打开设置。
- 时段显示可通过底部图标或 Ctrl+Shift+D 切换。
- 隐藏不等于退出：请从系统托盘菜单完全退出。
- 升级前导出备份；如开启过开机启动，先关闭。退出旧版后将新版解压到新文件夹运行，确认数据正常后再按需启用开机启动。
- 默认数据目录为 `%LocalAppData%\TodayChecklist`；已选择自定义目录的继续使用原目录。请勿删除数据目录。
- 完整说明见 [免安装版使用说明](PORTABLE.txt)；下载包内也有 `使用说明.txt`。
