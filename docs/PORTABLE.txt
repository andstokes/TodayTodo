今日清单 — ZIP 免安装版使用说明

适用范围
本发布版面向 Windows 11 x64（Intel/AMD 64 位电脑）。
软件自带 .NET 运行时，无需另外安装 .NET 或开发工具。
以普通用户权限运行，默认离线；无联网、遥测、广告或自动更新功能。
正式发布状态及实际验收结果以该 ZIP 对应的验收记录为准。

首次使用
1. 将 ZIP 完整解压到你有权限访问的本地文件夹。
2. 打开解压后的 TodayChecklist 文件夹，双击 TodayChecklist.exe。
3. 保留文件夹内所有 DLL、JSON、语言资源及其他运行文件；不要只移动 EXE。
4. 使用底部“＋”添加任务。隐藏窗口后可通过系统托盘重新显示。
5. 要完全关闭程序，请从托盘菜单选择“退出”。
不要在压缩包预览窗口中直接运行，也不需要以管理员身份运行。

任务与设置保存在哪里
默认保存于 %LocalAppData%\TodayChecklist。
如果你已在设置中选择其他数据位置，将继续使用原有位置。
程序与数据分别保存；删除或替换软件文件夹不会删除独立保存的任务数据。
数据目录含任务、设置和备份，不能作为软件分发包发给其他人。
仅将软件文件夹复制到另一台电脑不会同时带走数据。

更新版本
1. 用旧版的导出功能保存一份备份。
2. 如已开启开机启动，先在旧版设置中关闭。
3. 从系统托盘彻底退出旧版。
4. 将新版 ZIP 解压到新的文件夹，双击新版 TodayChecklist.exe。
5. 确认任务、设置和历史记录正常，再按需在新版中开启开机启动。
6. 确认新版正常后，可删除旧版程序文件夹。保留数据及导出备份。
请勿在旧版仍运行时覆盖其文件。新版会与旧版共用现有数据位置。
本版保持既有数据格式；跨机器迁移请通过导出、导入完成。
导入会替换当前任务及历史记录，程序会保留导入前备份。

可选功能
在设置中心可关闭“显示任务的已顺延天数”，隐藏顺延文字但不影响实际跨日规则。
时段分隔线默认关闭。在设置中启用，或点击底部分隔线图标、在主窗口按 Ctrl+Shift+D 开关。
上午、下午、晚上使用蓝色半粗体居中显示。开关的蓝色勾号表示开启，灰色斜线表示关闭；悬停可查看操作提示。
按住上午、下午或晚上的分隔线拖动，可调整时段边界；三条线不能相互越过。
也可拖动任务跨线安排。首次启用和新增任务默认归上午；上午线之前的任务表示暂未分时段。
已完成任务在单独的“已完成”区置底，取消完成后回到原时段。
关闭分隔线保留任务排列；在无分隔线模式下调序时，任务时段随相邻任务调整。
设置、任务顺序和所属时段会保存，退出再打开仍有效。
开机启动默认关闭，只通过当前用户 Startup 文件夹的快捷方式实现。
移动程序目录前应先关闭开机启动，移动后再重新开启。
标准窗口模式为默认值；桌面模式为实验性功能，不可用时使用标准模式。

移除软件
如启用过开机启动，先在当前程序设置中关闭，再从托盘退出，删除程序文件夹。
数据会保留。需要移除数据时，先导出备份并确认设置中显示的数据位置。

依赖许可
licenses 文件夹保留随实际运行依赖提供的许可证、第三方声明和原始 NuGet 元数据。
部分依赖包只提供许可链接，该链接原样保留在对应的 nuspec 文件中。
